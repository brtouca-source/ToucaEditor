Touca Editor Desktop v26.0.0 RC

Primeira candidata da versão definitiva baseada diretamente na v25.

Principais alterações estruturais:
- persistência de projetos e mídias em disco com schema versionado;
- importação nativa para evitar Base64 em mídias grandes;
- proxies locais para preview quando FFmpeg estiver disponível;
- drag/resize unificado e feedback visual fluido;
- duração persistente de ANI/TRAN;
- áudio/mux/export desktop via FFmpeg quando instalado;
- preview adaptativo e cache;
- redução de ruído não destrutiva;
- duplicação/renomeação/thumbnail de projetos;
- keyframe final automático mantido um pouco afastado do limite final, de forma proporcional.

Padrão de exportação: 1080p, H.264, 30 fps, 12 Mbps; 60 fps opcional.

Esta build é uma Release Candidate para teste real antes de publicação pública.
